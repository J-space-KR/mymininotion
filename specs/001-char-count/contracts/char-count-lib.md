# Contract: 글자 수 계산 함수 (`lib/charCount.ts`)

순수 함수만 둔다. 화면·저장소에 의존하지 않는다. 모든 기대값은 손으로 센 리터럴로 테스트한다.

## `countChars(text: string): { withSpaces: number; withoutSpaces: number }`

| 입력 | withSpaces | withoutSpaces | 확인하는 규칙 |
|---|---|---|---|
| `""` | 0 | 0 | 빈 내용 |
| `"안녕하세요"` | 5 | 5 | 한글 기본 |
| `"안녕 하세요"` | 6 | 5 | 띄어쓰기 |
| `"할 일 정리"` | 6 | 4 | 공백 여러 개 |
| `"가\n나"` | 3 | 2 | 줄바꿈 1자 (FR-003) |
| `"가\r\n나"` | 3 | 2 | CR+LF도 1자 (Q2) |
| `"  \n"` | 3 | 0 | 공백·줄바꿈만 |
| `"\t가"` | 2 | 1 | 탭은 공백 |
| `"　가 "` | 3 | 1 | 전각 공백·NBSP는 공백 |
| `"👍"` | 1 | 1 | 이모지 1자 (FR-004) |
| `"👨‍👩‍👧"` | 1 | 1 | ZWJ 결합 이모지 1자 |
| `"é"` | 1 | 1 | 결합 문자 1자 |
| `"ㅎ"` | 1 | 1 | 조합 중 자모 |

## `formatCount(n: number): string`

| 입력 | 출력 |
|---|---|
| 0 | `"0"` |
| 999 | `"999"` |
| 1000 | `"1,000"` |
| 1234567 | `"1,234,567"` |

## `parseTarget(input: string): { value: number | null; error: string | null }`

| 입력 | value | error |
|---|---|---|
| `""` | null | null |
| `"   "` | null | null |
| `"5000"` | 5000 | null |
| `"5,000"` | 5000 | null |
| `" 1000 "` | 1000 | null |
| `"1"` | 1 | null |
| `"1000000"` | 1000000 | null (상한 없음) |
| `"0"` | null | 안내 문구 |
| `"-5"` | null | 안내 문구 |
| `"1.5"` | null | 안내 문구 |
| `"abc"` | null | 안내 문구 |
| `"99999999999999999999"` | null | 안내 문구 (안전한 정수 범위 밖) |

안내 문구(해요체, DESIGN §7): `"1 이상의 숫자를 넣어 주세요"`.
테스트는 문구 원문이 아니라 `error !== null` 여부로 확인한다 (변경 감지기 금지, 헌법 II).

## `overBy(count: number, target: number | null): number`

| count | target | 결과 |
|---|---|---|
| 5 | null | 0 |
| 9 | 10 | 0 |
| 10 | 10 | 0 (같으면 초과 아님) |
| 11 | 10 | 1 |
| 12 | 10 | 2 |
